# tgbup: метаданные сообщений (превью ссылок, геолокация, контакты, опросы, чеклисты) — дизайн

Дата: 2026-10-01
Статус: реализован

## 1. Цель

Сейчас из медиа сообщения разбираются только фото и документы. Превью ссылок
(картинка, сайт, заголовок, описание), геолокация и места, контакты, опросы и
чеклисты в архиве видны только внутри исходного TL-блоба `raw`. Нужно сохранять
их в читаемом виде на момент выгрузки и показывать в `html/`/`md/`.

## 2. Решения

- **Одно расширяемое поле** `messages.meta_json` (миграция 005): JSON-объект,
  ключ — вид метаданных. Новые виды добавляются ключами, без миграций.
- Данные — **как Telegram отдал их при выгрузке**; позже не обновляются.
- **Уже скачанные сообщения не разбираются** (пользователь выгрузит заново).
  `raw` хранится всегда, поэтому разбор задним числом можно добавить позже.
- Карта — **только ссылка на Google Maps**; картинки карт не скачиваются.
- Если у ссылки не было превью в Telegram, сайт сами не опрашиваем.

## 3. `meta_json`

```json
{
  "webpage": {"url": "", "display_url": "", "site_name": "", "title": "", "description": "", "type": "", "photo_key": "photo:123"},
  "geo":     {"lat": 44.8, "long": 20.4, "accuracy": 0},
  "venue":   {"title": "", "address": "", "provider": ""},
  "live":    {"period": 900, "heading": 0},
  "contact": {"first_name": "", "last_name": "", "phone": "", "user_id": 0},
  "poll":    {"question": "", "answers": [{"text": "", "voters": 0, "correct": false}], "total_voters": 0,
              "closed": false, "quiz": false, "multiple": false},
  "todo":    {"title": "", "items": [{"id": 1, "title": "", "done_by": 0, "done_at": 0}],
              "others_can_append": false, "others_can_complete": false},
  "dice":    {"emoji": "🎲", "value": 4},
  "other":   {"type": "messageMediaStory"}
}
```

- `geo` есть у геоточки, места (`venue`) и трансляции (`live`, последняя точка).
- Картинка превью скачивается как обычное медиа (`photo:<id>`, связь через
  `message_media`), `webpage.photo_key` на неё ссылается; попадает в `media/`,
  `files/`.
- Прочие виды медиа (история, игра, счёт, розыгрыш, платное медиа) — `other`
  с именем типа.

## 4. Отрисовка

- Превью ссылки — карточка: картинка (если скачана), сайт, заголовок
  (ссылкой на `url`), описание.
- Геолокация — `📍 <название>, <адрес>` + координаты, ссылка
  `https://www.google.com/maps/search/?api=1&query=<lat>,<long>`; трансляция —
  пометка `live location (last point)`.
- Контакт — имя и телефон (`tel:`).
- Опрос — вопрос, варианты с процентами и числом голосов, итог голосов,
  пометки `quiz`/`closed`; правильный ответ викторины отмечен.
- Чеклист — заголовок и пункты `☑`/`☐`; у выполненного — кто и когда.
- Кубик — `🎲 4`. Прочее — `<type>`.
- Markdown — то же текстом; чеклист как `- [x]`/`- [ ]`.
- Поиск включает заголовок и описание превью, название и адрес места, имя
  контакта, вопрос и ответы опроса, пункты чеклиста.

## 5. Тесты

- `convert`: `meta_json` для каждого вида; картинка превью — второе медиа и
  `FileLocation` для неё; сообщение без медиа — пустое поле.
- `store`: поле пишется и читается.
- `render`: карточки HTML и Markdown для каждого вида; поисковый текст.
- e2e (тестовые серверы): геоточка, место, контакт и опрос из fixture
  сохраняются и видны на странице.
