# tgbup: рендеринг архива в HTML и Markdown, экспорт чата — дизайн

Дата: 2026-10-01
Статус: согласован в чате
Основа: `2026-09-28-tgbup-design.md` (план 2 — читаемый архив)

## 1. Цель

Архив (`archive.sqlite` + `media/`) нужно читать без Telegram: в браузере и в
Obsidian на Маке, а отдельный чат (или топик, или период) — отправить другому
человеку вместе с медиа, чтобы тот открыл его на компьютере.

Критерий успеха: после `sync` в `~/TelegramArchive/html/index.html` виден список
чатов, страницы по месяцам с медиа прямо в ленте и поиск по всему архиву;
`md/` открывается как хранилище Obsidian; `tgbup export Family -o family.zip`
даёт zip, который у получателя открывается двойным кликом по `index.html`.

## 2. Решения

- **Статичные файлы**, без сервера; пересобираются после `sync` только там, где
  что-то изменилось.
- **Читатель — владелец на Маке** (браузер с JavaScript, Obsidian). Получатель
  экспорта — компьютер.
- Результат лежит **в корне архива рядом с `media/`**, поэтому ссылки на медиа
  одинаковы в архиве и в экспорте.
- `html/` и `md/` — производные, в бэкап не входят (как `files/`).

## 3. Раскладка

```
<archive>/
  html/index.html                    список чатов + поиск
  html/assets/style.css, search.js
  html/search/<chat-id>.js           индекс поиска чата
  html/<чат>/index.html              месяцы; у форума — топики → месяцы
  html/<чат>/<топик>/2026-03.html    сообщения месяца (форум)
  html/<чат>/2026-03.html            сообщения месяца (не форум)
  md/<чат>/[<топик>/]2026-03.md
  media/…                            без изменений
```

- Имена папок чатов и топиков — очищенные названия, как в `files/`
  (`browse`): без `/ \ : * ? " < > |`, управляющих символов и ведущих точек; чаты
  с одинаковым названием различаются ` (id)`. Старая группа, из которой вырос
  форум, рисуется отдельным разделом `before upgrade` внутри папки форума.
- Время — местное.

## 4. Страница месяца

Каждое сообщение — блок с якорем `#m<id>`:

- автор (имя пользователя из `users`, название канала/группы из `peers`/`chats`;
  неизвестный — `Deleted account` / `id`), время `15:04`, пометки `edited`
  (есть `edit_date`), `pinned`;
- текст с разметкой по `entities_json` (смещения в UTF-16): bold, italic,
  underline, strike, code, pre, spoiler (раскрывается по клику), text_url,
  url/email/phone (ссылки), mention/mention_name, hashtag; весь текст
  HTML-экранирован, ссылки только `http(s):`, `mailto:`, `tel:`, `tg:`;
- ответ: цитата (автор + первые 100 символов) со ссылкой на
  `<страница месяца исходного>#m<id>`; исходного нет в архиве — `reply to a
  message not in the archive`;
- пересылка: `Forwarded from <имя или from_name>` и исходная дата;
- медиа (по `media.status`):
  - `done`: photo/sticker — `<img loading=lazy>` со ссылкой на файл;
    video/video_note/animation — `<video controls preload=none>`;
    voice/audio — `<audio controls preload=none>`; document — ссылка
    `имя · размер`;
  - иначе заглушка: `<kind> not downloaded: <причина>` (skipped — текст
    причины, failed — ошибка, pending — `pending`);
- служебное сообщение — строка по центру: `pinned a message`, `created topic
  «…»`, `joined`, `left`, `changed the title to «…»`, `changed the photo`,
  прочие — имя типа действия;
- реакции: `👍 3 · ❤ 2` (custom emoji — `★ n`, paid — `⭐ n`).

Вверху страницы: хлебные крошки `Archive › Чат › Топик › 2026-03`, ссылки на
предыдущий/следующий месяц. Светлая и тёмная тема по системной настройке.

## 5. Markdown

Тот же контент: `**Автор** · 15:04` + текст с Markdown-разметкой (bold, italic,
strike, code, pre, ссылки), ответ — `> Автор: цитата`, медиа — `![](../../media/…)`
для картинок, `[имя](…)` для остального, заглушка текстом. Заголовок файла —
`# Чат › Топик · 2026-03`.

## 6. Поиск

- `html/search/<chat-id>.js` — `tgbupSearch.add({chat, entries:[[id, date, page, text]]})`;
  текст — обычный текст сообщения (без разметки), для медиа — имя файла.
- `index.html` подключает все индексы `<script>`-тегами (fetch на `file://`
  запрещён) и ищет подстроку без учёта регистра; выдача — дата, чат, топик,
  фрагмент вокруг совпадения, ссылка на сообщение; не больше 200 результатов.

## 7. Обновление

- Таблица `render_pages` (миграция 004): `chat_id, topic_id, month,
  fingerprint`. Отпечаток месяца — хэш от `count(*)`, `max(id)`,
  `max(edit_date)`, `sum(pinned)`, числа реакций и статусов медиа сообщений
  месяца.
- После `sync` (после `files/`) и в `tgbup render`: перерисовываются страницы с
  изменившимся отпечатком; оглавления, индексы поиска, `index.html`, assets —
  всегда. `tgbup render --full` — всё. Страницы чатов, которых больше нет среди
  активных, не удаляются (архив ничего не удаляет).
- Запись страницы: временный файл рядом → rename.
- Ошибка страницы не останавливает остальные; `sync` показывает `render: …` и
  выходит с кодом 1; `render_pages` для неё не обновляется.

## 8. Экспорт

```
tgbup export <чат> [--topic <название|#id>] [--from YYYY-MM] [--to YYYY-MM] [--no-media] -o file.zip
```

- `<чат>`: числовой ID, `@username` или точное название (без учёта регистра);
  несколько совпадений — ошибка со списком ID.
- В zip: `index.html` (перенаправляет на страницу чата), `html/` и `md/`,
  отрисованные заново только для выбранного, `media/` — копии файлов, на
  которые ссылаются выбранные сообщения (не с `--no-media`).
- Ответы на сообщения вне выбранного — цитата без ссылки.
- Перед записью печатается `N messages, M files, ~X MB`; zip пишется во
  временный файл → rename.
- Коды выхода: 0; 1 — ошибка записи/чтения; 2 — неверные флаги, чат/топик не
  найден.

## 9. Компоненты

| Где | Что |
|---|---|
| `internal/store` | миграция 004; запросы: чаты/топики/месяцы, сообщения месяца с медиа и именами, отпечатки, сообщения по ID |
| `internal/render` (новый) | модель страницы, разметка entities → HTML/Markdown, шаблоны (`html/template`, `text/template`, `embed`), запись страниц, индекс поиска, инкрементальность |
| `internal/browse` | экспорт функции очистки имени (`Clean`) для общих имён папок |
| `cmd/tgbup` | `render`, `export`; вызов после `sync`; сводка |

## 10. Тесты

- Разметка entities: вложенные и пересекающиеся, суррогатные пары (эмодзи),
  экранирование HTML, опасные ссылки (`javascript:`).
- Эталонные фрагменты страницы для каждого вида сообщения и медиа, заглушки.
- Markdown для тех же случаев.
- Инкрементальность: без изменений ничего не перерисовано; новое сообщение /
  правка / скачанный файл перерисовывают только свой месяц.
- Ответ на сообщение из другого месяца ведёт на нужную страницу.
- Экспорт: состав zip, фильтры топика и периода, `--no-media`, ненайденный чат.
- e2e (тестовые серверы): `sync` строит `html/index.html` и страницу месяца
  fixture-форума с текстом и ссылкой на документ; `export` форума даёт zip с
  документом.

## 11. Вне области

Альбомы как галереи (каждое сообщение отдельно); превью ссылок; отрисовка
custom emoji; полнотекстовый поиск с морфологией; веб-сервер; PDF.
